# (E)XtEnded Modding Tree

Heavily modified version of [TMT](https://github.com/Acamaeda/The-Modding-Tree) ( The Modding Tree ).
It's modified to greatly improve performance on larger scale trees, for comparison to "The Vorona Tree" and add some features while fixing some things in addition.

Here is general comparsion between two engines: ( not glazing my creation )
| XeMT                                          |                                       TMT  |
| :-------------------------------------------- | -----------------------------------------: |
| Utilizes WebWorkers                           | Single core limitation                     |
| Better functionality                          | Passable but could be improved             |
| Not internet dependant                        | Internet dependant for CDNs                |
| Integrated Galaxy.click cloud saving!         | Local saving, prone to accidental deletion |
| May be very large in default project size     | Relatively small                           |
| May be difficult to mod                       | Meant to be easily moddable                |
